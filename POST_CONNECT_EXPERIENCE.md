# Media Studio — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
Контент-менеджер/SEO-специалист, который готовит статьи к публикации и должен быстро
получить готовые, релевантные изображения (featured + inline) без найма дизайнера и без
собственной работы в Midjourney/Photoshop.

## 2. Момент истины после подключения
Сразу после `connect_magnific` — можно тут же вызвать `list_media_packages` и увидеть все
уже существующие брифы по проектам (сайтам), их статус (draft/generating/ready/failed) и
сколько картинок в каждом уже готово.

## 3. Что пользователь видит
- Проекты (подключённые сайты), под которые готовятся изображения — `list_projects`,
  `get_project` (описание, дефолтный стиль/язык, количество брифов).
- Медиа-брифы и их статус готовности — `list_media_packages`, `get_media_package`.
- Каждый ассет внутри брифа: featured/inline картинка, её alt text, caption, prompt,
  провайдер и модель, которой сгенерирована — `get_media_package`.
- Историю ежедневных проверок на новые модели генерации у Magnific —
  `list_model_discovery_log`.
- Журнал самопроверок движка промптов (что и когда пересматривалось) —
  `list_prompt_engine_log`.

## 4. Чем пользователь может управлять
- Создать новый бриф под конкретную статью (заголовок, саммари, стиль, число inline-
  картинок, политику текста в изображении) — `create_media_brief`.
- Запустить фактическую генерацию всех картинок брифа — `generate_media_package`
  (работает в фоне, с уведомлением по готовности).
- Перегенерировать только один ассет (например, только featured-картинку) без пересборки
  всего брифа — `regenerate_asset`.
- Создать увеличенную (upscale) версию готовой картинки — `generate_asset_upscale`.
- Отредактировать title/alt/caption ассета без перегенерации самой картинки —
  `update_asset_meta`.
- Настроить параметры движка промптов (освещение, камера/объектив по умолчанию) —
  `save_prompt_engine_config`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'сделай бриф на статью про установку кондиционера, 2 inline-
картинки, без текста на изображении'. Она создаёт бриф через `create_media_brief`, потом
`generate_media_package` реально генерирует готовые фото через Magnific — с alt text на
языке статьи — за минуты, а не за день ожидания дизайнера."

## 6. Что делает это "заточенным под него"
`create_project`/`update_project` хранят дефолтный стиль и язык именно ДЛЯ ЭТОГО сайта —
каждый новый бриф автоматически наследует правильную визуальную стилистику бренда клиента,
а не общий шаблон.
